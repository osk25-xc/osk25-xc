## 🔍 My Analytics Workflow

<div align="center">

**Understand the Problem** → **Check Data Quality** → **Analyze** → **Visualize** → **Communicate Insights**

</div>

1. Translate business requirements into clear questions and KPIs.
2. Inspect data types, missing values, duplicates, and assumptions.
3. Analyze information using SQL, Excel, or Python.
4. Build clear reports, charts, and dashboards.
5. Explain findings, limitations, and actionable next steps.
