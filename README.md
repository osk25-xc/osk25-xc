These projects are hands-on portfolio work using practice datasets. Project descriptions explain the analysis focus; check each repository for the current files, implementation, and outputs.

### 📊 Excel & Power BI

**1. [Retail Sales Analysis — Excel](https://github.com/osk25-xc/Retail-Sales-Analysis-Excel)**

An Excel reporting project focused on understanding retail sales and operational performance.

- **Analysis:** Sales, profit, profit margin, target achievement, delivery and return measures (where available in the workbook).
- **Techniques:** Excel formulas, PivotTables, PivotCharts, slicer-based filtering, KPI reporting.
- **Goal:** Make performance comparisons across regions, categories, and time easier to understand.

**2. [Retail Sales Analysis — Power BI](https://github.com/osk25-xc/Retail-Sales-Analysis-PowerBI)**

A Power BI report project for reviewing retail performance through interactive visuals.

- **Analysis:** Sales, profit, distinct orders, profit margin, regional and category performance.
- **Techniques:** Power Query, data modeling, DAX measures, date analysis, slicers, KPI cards.
- **Goal:** Present business performance in a clear and interactive report.

### 🗃️ SQL & Business Analysis

**3. [SQL Business Sales Analysis](https://github.com/osk25-xc/SQL-Business-Sales-Analysis)**

A SQL project that explores business performance from e-commerce transaction data.

- **Business questions:** Which products and categories contribute most? Who are the top customers? How does monthly revenue change?
- **SQL concepts:** Aggregations, JOINs, CASE, subqueries, CTEs, ranking, and LAG/window functions.
- **Goal:** Turn transaction-level data into repeatable business summaries.

**4. [Superstore Sales Analysis](https://github.com/osk25-xc/Superstore-SQL-Analysis)**

Retail analysis focused on sales, profit, customer and product performance.

- **Analysis:** Category and regional performance, monthly trends, profitability, and loss-making transactions.
- **Tools:** SQL, Python, Pandas, NumPy, Matplotlib, Seaborn.
- **Goal:** Explore the factors and segments behind sales and profitability patterns.

**5. [E-commerce Sales Analysis](https://github.com/osk25-xc/Ecommerce-Sales-Analysis)**

A project for examining e-commerce transaction data and defining useful business metrics.

- **Analysis:** Sales trends, product/category contribution, customer contribution, and data-quality checks.
- **Workflow:** Inspect schema → validate records → define KPIs → analyze trends → document findings.
- **Goal:** Build a reliable foundation for e-commerce reporting.

### 🐍 Python & Customer Analytics

**6. [Customer Churn Analysis](https://github.com/osk25-xc/Customer-Churn-Analysis)**

A descriptive customer analytics project to explore churn patterns.

- **Analysis:** Overall churn, churn across customer groups, contract/payment patterns, tenure, and charges.
- **Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.
- **Goal:** Identify customer segments that may need further retention analysis.

**7. [Retail Customer Segmentation — RFM](https://github.com/osk25-xc/Retail-Customer-Segmentation)**

A customer segmentation project using purchasing behavior.

- **RFM metrics:** Recency, Frequency, and Monetary value.
- **Additional work:** Data-quality audit, input validation, and automated unit tests.
- **Tools:** Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook, GitHub Actions.
- **Goal:** Understand customer purchasing patterns and create useful customer groups.

**8. [HR Analytics — Employee Performance](https://github.com/osk25-xc/HR-Analytics-Employee-Performance)**

A people-analytics project exploring workforce patterns.

- **Analysis:** Attrition, department/job-role patterns, overtime, tenure, satisfaction, and salary distribution.
- **Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.
- **Goal:** Summarize workforce trends and identify questions for deeper HR investigation.

### ⚙️ Machine Learning Engineering

**9. [Customer Churn Prediction — MLOps](https://github.com/osk25-xc/mlops-churn-project)**

A learning project exploring an end-to-end machine-learning workflow.

- **Workflow:** Exploratory analysis, feature engineering, model training, experiment tracking, API serving, and containerization.
- **Tools:** Python, Pandas, Scikit-learn/XGBoost (as implemented), MLflow, FastAPI, Streamlit, Docker.
- **Goal:** Understand how a model workflow can be organized beyond notebook experimentation.
